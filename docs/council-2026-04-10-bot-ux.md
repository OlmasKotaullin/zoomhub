## Консенсус (все 4 эксперта)

### 1. ZoomHub уже выигрывает по качеству, проигрывает по упаковке

| | ZoomHub | Буквица |
|---|---|---|
| Таймкоды | ✅ У каждого сегмента | ❌ Один 00:00:00 на весь текст |
| Сегментация | ✅ Логические фразы | ❌ Стена текста |
| AI-чат | ✅ Есть (на сайте) | ❌ Нет |
| Поиск | ✅ Есть | ❌ Нет |
| Веб-интерфейс | ✅ Полный дашборд | ❌ Только бот |
| **Inline-кнопки** | ❌ Только "Открыть на сайте" | ✅ "Конспект" / "Умный конспект" |
| **.txt файл** | ❌ Нет | ✅ Присылает автоматически |
| **Брендинг** | ❌ Нет | ✅ "Создано в Буквица" |
| **callback_query** | ❌ Не обрабатывается | ✅ Работает |

### 2. Главный принцип: инвертировать информационную архитектуру

**Буквица:** стена текста сразу → конспект по кнопке
**ZoomHub:** конспект сразу → транскрипт по кнопке

Это наше ключевое отличие. 80% юзеров достаточно конспекта. Транскрипт — для проверки деталей.

### 3. Формат ответа бота (утверждён всеми)

```
✅ Еженедельная планёрка ВИМОС

17 мин | 12 847 символов | 3 задачи

Руководитель Саша отчитался по итогам марта.
KPI выполнены на 87%. Обсудили проблему
с поставщиком фурнитуры и план на апрель.

Задачи:
  • Саша — подготовить сравнение поставщиков к среде
  • Михаил — закрыть дебиторку по ООО Стройка
  • Лена — обновить скрипт для новых клиентов

Темы: итоги марта, KPI, поставщик фурнитуры

──────────────
Создано в ZoomHub

[ 📄 Транскрипт ]  [ 💬 AI-чат ]
[    🌐 Открыть на сайте    ]
```

### 4. Прогресс-бар через editMessage (вместо потока сообщений)

```
⏳ Обрабатываю запись...

✓ Скачано
— Транскрипция...
  Конспект
```

→ обновляется по мере прогресса → удаляется при готовности → заменяется финальным результатом.

### 5. .txt файл с таймкодами — killer feature

По кнопке "Транскрипт" бот отправляет .txt:
```
Еженедельная планёрка ВИМОС
10 апреля 2026 | 17 мин
---

[00:00:00] Так, ВИМОС на 31 марта...
[00:00:16] Саша, предлагаю 10 минут на доклад...
[00:00:38] Тогда начнем, наверное, да...

---
Транскрибировано в ZoomHub — zoomhub.ru
```

У Буквицы .txt без таймкодов — мы объективно лучше.

### 6. AI-чат в Telegram — дифференцирующая фича

Режим чата: кнопка "AI-чат" → бот входит в режим вопрос-ответ по записи:

```
Пользователь: Что решили по бюджету?

ZoomHub: В таймкоде 08:42 Алмаз предложил бюджет
150К/мес на Яндекс Директ. Решили начать с поиска.

Источник: 08:42 — 11:15
```

Таймкоды источников в ответах — то, чего нет ни у кого.

## Приоритеты реализации

### Фаза 1 — MVP (4-5 часов)
1. Callback query handler в webhook
2. Новый `_send_result` с метриками + 3 кнопки + брендинг
3. Генерация .txt с таймкодами по кнопке
4. Прогресс через editMessage (3 этапа)

### Фаза 2 — Дифференциация (1-2 дня)
5. AI-чат в Telegram (режим вопрос-ответ)
6. AI-шаблоны по кнопкам (протокол, задачи, follow-up)
7. /meetings — список последних записей
8. /plan — тариф и лимиты

### Фаза 3 — Growth (2-3 дня)
9. Кнопка "Поделиться" + реферальная механика
10. Upsell Pro-фич каждые 3 записи
11. Уведомление при приближении к лимиту
12. Групповой режим бота (для рабочих чатов)
