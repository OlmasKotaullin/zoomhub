## CPO — Продуктовый анализ

### Кто реально потребляет 6-10ч/день
1. **Ресёрчеры/UX** — 3-6ч, высоко ценный сегмент
2. **Коучи/психологи** — 4-7ч, готовы платить
3. **Подкастеры** — заливают чужой контент (грань абьюза)
4. **Образование** — 1 аккаунт на кафедру (абьюз)
5. **Реселлеры** — чистый абьюз

### Как другие SaaS решают

| Сервис | Модель |
|---|---|
| Otter.ai | Жёсткие лимиты: 300 мин free, 1200 мин pro ($17), 6000 мин biz ($30) |
| Fireflies.ai | «Бесплатная» транскрибация, лимит на хранение |
| Loom | Безлимит количества, лимит длительности видео |
| Notion | Безлимит на дешёвое (блоки), AI тарифицируется отдельно |

**Ни один SaaS в нише не даёт реального безлимита на compute-heavy операции.**

### Скрытые ограничители Буквицы
1. Макс. длина файла — 4 часа
2. Макс. размер — 9ГБ видео / 2ГБ аудио
3. Только Telegram-бот (нет API, нет массовой загрузки)
4. Очередь при высокой нагрузке

**Ключевой инсайт:** Чем удобнее ZoomHub (веб, Zoom-интеграция, автозапись), тем выше реальное потребление и тем опаснее слово «безлимит».

**Вердикт CPO:** 100ч на Про + мягкий безлимит (fair use) + лимит на длину файла + concurrent limit.

## CTO — Техническая оптимизация

### Roadmap снижения COGS

| Оптимизация | Экономия | Сложность | Фаза |
|---|---|---|---|
| Turbo модель | **−63%** | 1 строка | Сейчас |
| Удаление тишины (ffmpeg) | **−15-25%** | Пара часов | Сейчас |
| int8 квантизация | **−20-30%** | 1 строка | Сейчас |
| Audio hash кэш | **−5-15%** | Средняя | 1-4 нед. |
| Rate limiting | Защита | Средняя | 1-4 нед. |
| Dedicated GPU гибрид | **−50-70%** | Высокая | 3-6 мес. |

**Кумулятивный эффект Фазы 0:** $0.079 → **$0.017/час** (снижение на 78%)

### Точка перехода на Dedicated GPU

- RunPod Serverless: $0.029/час (turbo)
- RTX 4090 аренда: $288/мес = ~43,200ч аудио при 100% утилизации
- **Breakeven: ~1000 юзеров** (утилизация >35%)

### Must-have до масштабирования
- Жёсткие лимиты на файл (4ч, 2ГБ)
- Месячные лимиты по тарифу
- Concurrent processing limits (1/3/5)
- Abuse detection (hash-дубликаты, массовые загрузки)

## Консенсус (все 4 эксперта)

1. **Убрать «безлимит» из тарифа Про.** Заменить на 100ч/мес — 97% юзеров не заметят, но защита от убытков.

2. **Добавить доп.часы сверх лимита** (10-15₽/час) — монетизация тяжёлых юзеров вместо убытков.

3. **Внедрить жёсткие лимиты немедленно:** макс. длина файла 4ч, concurrent 3-5, месячный metering.

4. **Turbo + preprocessing — первый приоритет** (снижение COGS на 78% за 1 день работы).

5. **Буквица выживает за счёт:** собственных GPU (~3₽/ч), 35K юзеров (усреднение), Telegram-friction. Мы пока не можем копировать эту модель.

6. **LLM-саммари — не менее дорогая статья, чем транскрибация.** При 8₽/встречу на Claude это 50%+ COGS.
